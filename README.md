# Madhavi Soni — Engineering Portfolio

A responsive, static portfolio website built from Madhavi's supplied resumes and project portfolio images. No build tools or hosting fees required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Unzip this folder. Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder to the **root** of your repository. Do not upload the enclosing `madhavi-engineering-portfolio` folder as a single nested folder.
3. Commit the files.
4. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait a few minutes and open `https://YOUR-USERNAME.github.io/`.

Alternatively, use any repository name, such as `engineering-portfolio`, and your URL will normally be `https://YOUR-USERNAME.github.io/engineering-portfolio/`.

## Edit content

- Update text and links in `index.html`.
- Update project details in `script.js`.
- Change colors and layout in `style.css`.
- Replace/add photos in `assets` and update the filenames referenced by the HTML/JavaScript.
- The site uses a Google Fonts import; the fallback system fonts work if the service is unavailable.

## Before publishing

- Check that all project descriptions accurately reflect your contributions and project stage.
- Add a downloadable resume only if you want to make it public; no PDF resume is included by default to avoid publishing your phone number.
- Confirm that any team-owned or research images are approved for public display. Images were extracted from the supplied portfolio PDF.
- Test on mobile and desktop.
